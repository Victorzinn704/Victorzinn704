## Sobre

Construo software para problema concreto. Hoje meu foco principal e o **Desk Imperial**, uma plataforma full-stack para pequenos comerciantes brasileiros, com PDV, comandas, financeiro, folha de pagamento, operacao mobile e tempo real.

Tambem mantenho projetos menores para estudar fundamentos, testar tecnologias e mostrar evolucao fora da stack principal. Nem todo repositorio aqui e produto final. Alguns sao estudo, outros sao portfolio tecnico, e os forks existem para contribuicoes pontuais em projetos externos.

- Prefiro prova executavel a descricao vaga.

- Quando um projeto ainda e estudo, deixo isso claro.
